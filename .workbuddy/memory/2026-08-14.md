# 2026-08-14 工作日志

## 功能:离线账户导入自定义皮肤(此前仅正版/Microsoft 可上传皮肤)

### 需求
- 现状:只有 Microsoft 正版账号能通过 `MinecraftSkinService` 上传皮肤到 Mojang;离线账号被拒("仅支持正版皮肤上传")。
- 目标:离线账号也能导入自定义皮肤,无需正版账号、无需装 Mod。

### 方案(仿 HMCL)
离线皮肤通过 **authlib-injector + 本地 Yggdrasil 皮肤服务** 注入:启动时给游戏附加
`-javaagent:authlib-injector.jar=<http://127.0.0.1:port> -Dauthlibinjector.side=client`,
游戏的所有会话服务请求被重定向到本地服务器,服务器返回带签名 textures 属性的玩家档案,
PNG 由 `/textures/<sha1>` 提供。单机与离线模式服务器均生效。

### 新增文件(ecl-core)
- `com/ecl/auth/OfflineSkin.java` — record(pngFile, variant),slim() 判断细手臂。
- `com/ecl/auth/OfflineSkinStore.java` — 持久化:PNG 复制到 `<base>/skins/<sha1(identity)>.png`,
  `skins.json` 记录 {identity → {file, variant}};identity 与 `AuthAccount.identity()` 一致
  (`OFFLINE:<uuid>`);`identityForOffline(username)` 供 GUI/CLI 未保存账号时推导。
- `com/ecl/auth/offline/OfflineSkinServer.java` — JDK `com.sun.net.httpserver` 实现的
  authlib-injector 协议服务器(仅绑定 127.0.0.1):`/`(signaturePublickey PEM + skinDomains + meta)、
  `/status`、`POST /api/profiles/minecraft`、`GET .../hasJoined`、`POST .../join`、
  `GET .../profile/<uuid>`(签名 textures 属性,RSA-2048 + SHA1withRSA)、`GET /textures/<sha1>`。
  进程内共享单例,textures 内存缓存上限 16 个。
- `com/ecl/auth/offline/AuthlibInjectorManager.java` — 下载/缓存 `authlib-injector.jar`(数据目录),
  源:官方 `authlib-injector.yushi.moe/artifact/latest.json` → BMCLAPI 镜像
  `bmclapi2.bangbang93.com/mirrors/authlib-injector/artifact/latest.json`;
  ZIP 魔数校验(防止 HTML 错误页)。注意:GitHub `latest/download` 资产名带版本号,不可用,勿回退到它。
- `com/ecl/auth/offline/OfflineSkinInjector.java` — 组装 javaagent JVM 参数。

## 审查:离线皮肤功能代码审查(4 子agent并行)

### 结论
无 P0。权限链路闭环正确:离线仅走本地导入、正版仅限 Microsoft+真 token、Yggdrasil 隐藏+防御拒绝、Injector 有 AuthType 闸门;identity 由 OfflinePlayer:<name> 确定性派生,导入/启动/注入三方一致;路径穿越防护正确(Path.startsWith 按段比较)。

### 需修复清单
- P1-1 `OfflineSkinServer.registerCharacter` textures 缓存淘汰:ConcurrentHashMap 非插入序,`keySet().iterator().next()` 不是最旧项,可能误删仍被 characters 引用的皮肤→游戏内 404。应改用 LinkedHashMap/显式 LRU。
- P1-2 `MinecraftSkinService.inspect` 先 ImageIO.read 解码(:46)后查尺寸(:47)→1MB 压缩 PNG 可解出数百 MB BufferedImage OOM。应先读 IHDR 宽高再解码。
- P1-3 `OfflineSkinStore.readIndex` 索引损坏抛 AuthException(RuntimeException),find/remove 不捕获→a)offlineSkinExists()(LauncherUI:2938)UI 线程穿透;b)启动流程 find 异常→整次游戏无法启动而非降级"无皮肤"。应降级 Optional.empty()。
- P2 群:upload 只验 token 非空不验 AuthType(离线 token="0" 可通过,纵深防御缺口);OfflineSkinStore 内部不做 identity 规范化且文件名 toLowerCase 与索引 key 不一致;用户名大小写敏感改名丢皮肤(UI 无提示);writeIndex 失败留孤儿 PNG、remove()(LauncherUI:3798)无 try-catch;实例级 synchronized+每次 new OfflineSkinStore 多实例并发丢更新;find 未限定 skins/ 子目录;SHA-1 可升 SHA-256;128×128 皮肤被拒、未校验 alpha;queryParameter 无 URL 解码(用户名含空格/+ hasJoined 失配);SHA1withRSA 可升 SHA256withRSA;0 字节文件文案误导;Yggdrasil 提示文案"仅支持正版"语义偏差;OfflineSkin 无归属字段依赖调用方。
- 测试缺口:魔数正反用例、0字节/>1MB、multipart 细节断言、401/500 降级、索引损坏降级、URL 编码。
