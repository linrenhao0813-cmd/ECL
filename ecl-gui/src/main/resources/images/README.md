# Forest launcher artwork

`forest-hero.png` is an AI-generated landscape produced with the built-in image_gen tool for ECL's forest UI redesign. It is bundled locally and requires no network access at runtime. It is decorative artwork, not a screenshot of the user's world. Buttons, text, and status values are native JavaFX controls.

Generation prompt (the chosen forest UI preview was supplied as a visual reference):

> Use case: stylized-concept. Create a production raster background asset ONLY for the ECL Minecraft launcher forest-green UI. A wide 3:1 panoramic Minecraft-style voxel conifer forest around a tranquil reflective alpine lake at dusk, distant block-built rocky mountains, soft warm sunset far right, deep forest green and muted gray palette, tasteful atmospheric haze, beautiful restrained shader lighting. Dense near-black forest at the far left, lake and mountain detail strongest center and right. All terrain and trees built of voxel cubes, cinematic but calm. Full bleed landscape, no UI, no text, no lettering, no logos, no buttons, no frames, no people. Match the peaceful forest landscape from the provided launcher reference, but produce clean environment artwork only with no interface.
